# 使用指南

> 目标架构中，账号由 **Auth.js（邮箱 + 密码）** 登录，科研与训练数据存储在平台自有的 **PostgreSQL**（经 Python 后端读写）。
>
> ⚠️ 重构进行中；旧本地密码 / Supabase 模式见文末[附录](#附录旧使用方式迁移中)。

---

## 一、角色

| 角色 | 范围 | 能力 |
| --- | --- | --- |
| 学员 `learner` | 全局默认 | 使用 7 大智能体；在所属训练营学习、提交、查看个人报告 |
| 馆员 `librarian` | 全局 + 院系 | 管理本院系训练营、审核、报表、导出 |
| 管理员 `admin` | 全局 | 跨院系管理、创建院系、全局配置 |
| 助教 `ta` | 仅某训练营 | 查看本营名单/报表/进度、审核与认领提交、催交、脱敏导出；**不能**建营/邀请/改 curricum |

> 助教不是全局 staff：账号 `users.role` 仍为 `learner`，但在该营 `enrollments.role = 'ta'`。

---

## 二、首次使用

1. 打开 iScholar（默认 `http://localhost:3000`），进入登录页。
2. 输入邮箱与密码登录（由 Auth.js 校验）。账号由管理员邀请或创建。
3. 登录后进入**仪表盘**。

> 🔒 忘记密码请联系管理员重置（目标平台不再支持纯本地密码找回）。

## 三、界面概览

### 落地页

- **北斗七星星座图**：7 颗星对应 7 大智能体，悬浮查看星名。
- 顶部导航、渐变标题、智能体展示卡与网格。

### 全局顶栏（仪表盘 / 项目 / 设置页）

- 左侧：iScholar logo + 项目选择器。
- 右侧：语言切换（简体中文 / English）、用户菜单。
- 侧边栏：仪表盘、项目、7 个智能体、设置。

### 智能体模块页（3 列全屏外壳）

进入智能体后切换为**全屏工作流外壳**（无全局侧栏），**3 列独立滚动**：

```text
┌──────────────────────────────────────────────────────────────┐
│ ← 返回   选题探索·学伴智枢    [已保存] [项目▾] [↻]            │  ← 顶栏（固定）
│ ①──②──③──④──⑤──⑥──⑦──⑧                                    │  ← 8 步工作流（固定）
│ [状态徽章] [操作按钮]                                        │  ← 状态栏（固定）
│ ┌────────┬──────────────────────────┬─────────────┐         │
│ │ 左列   │ 中列（主工作区）          │ 右列          │         │
│ │ 输入表单│ 实时预览 / 结果           │ 使用说明书    │         │
│ │ ↕ 独立 │ ↕ 独立                    │ ↕ 独立       │         │
│ └────────┴──────────────────────────┴─────────────┘         │
└──────────────────────────────────────────────────────────────┘
```

- **8 步工作流**：选题 → 综述 → 设计 → 数据 → 分析 → 写作 → 投稿 → 返修&展示；当前阶段以专属强调色高亮。
- **顶栏 / 步进条 / 状态栏固定**，仅内容区可滚动，各列独立滚动。
- **使用说明书**：右侧可折叠面板（角色、流程、流转说明）。

## 四、创建项目

1. 仪表盘或侧边栏点击 **「新建项目」**。
2. 填写：项目名称、学科领域、研究目标。
3. 创建后自动进入**选题探索**。

项目创建会经 BFF 调用后端 `POST /v1/data/projects`，写入 PostgreSQL 并归属当前用户。

## 五、研究工作流（7 大智能体）

统一操作模式：填写输入 → 运行 → 审核结果 → **批准 / 驳回** → **应用到论文**。运行由后端 LangGraph + `AgentHarness` 执行，事件经 SSE 实时推送，产物幂等落库。

### 1. 选题探索 · TopicScout
- 输入：学科领域、关键词（逗号分隔）、目标期刊（可选）。
- 左列：研究领域标签芯片 + 研究问题文本区。
- 中列：3 个候选选题卡片，附可行性（绿）/ 创新性（蓝）/ 研究价值（紫）徽章 + 进度条。
- 输出：评分柱状图 + 审计记录。
- 应用：写入论文 `topic` 区块。

### 2. 文献综述 · LitReview
- 输入：检索词、年份范围、最大结果数 + 数据库多选（PubMed/CNKI/WoS/Scopus）。
- 中列：文献表格，状态列用**可点击徽章**循环切换（已包含 / 未包含 / 待定）。
- 底部：研究缺口与建议。
- 应用：保存为**文献条目**。

### 3. 研究设计 · ResearchDesigner
- 左列：**PICO 2×2 卡片网格** + 研究类型分段控件（RCT / 队列 / 横断面）。
- 中列：变量表（名称/类型/测量方式），类型列徽章。
- 底部：生成设计文档 + 前往数据收集。

### 4. 数据分析 · DataPilot
- 中列：样本量 / 主要效应 / p 值·95% CI 指标卡片。
- 假设检验表 + 显著性徽章；SVG 森林图与箱线图。
- 应用：创建**实验记录**。

### 5. 论文撰写 · IMRaDWriter
- 左列：IMRaD 章节卡片（引言/方法/结果/讨论），点击切换。
- 中列：**富文本编辑器**，可即时编辑。
- 右列：引用管理器 + 格式与导出（PDF / Word）。
- 支持 **LaTeX**（`$...$`、`$$...$$`）与**引用插入**。

### 6. 投稿匹配 · SubmitMatch
- 左列：投稿表单 + 生成 Cover Letter。
- 中列：期刊匹配表（分区/影响因子/录用周期/**Fit-score** 环形进度条）。
- 右列：投稿材料 checklist（勾选后进度更新）。
- 应用：创建**投稿记录**；下载 **ZIP 投稿包**。

### 7. 返修与展示 · RebuttalShow
- 左列：审稿意见文本区 + PDF 上传 + 解析。
- 中列：逐条回复表（审稿人/类型/关联段落/状态）。
- 应用：创建**审稿轮次 + 回复条目**；导出 HTML 回复信。

## 七、AI 科研教练（训练营）

### 管理员 / 馆员

1. 登录（`admin` 或 `librarian`）。
2. 打开 `/training/manage` 选择院系/组织，创建训练营（名称、描述、学科、cohort、起止日期、人数、状态）。
   - 院系成员：按邮箱加入馆员
   - LMS 导出：Canvas / Moodle CSV，或配置 AGS 推送（见 [lms.md](./lms.md)）
3. 选中训练营后可：班级报表、数据导出（默认脱敏）、任务编排、成员与邀请、营脱敏同意审计、任务包、结业证、运营报表（`/training/analytics`）、成绩册导出。
4. 打开 `/training/review`：筛选任务与状态、查看证据卡、反馈模板、认领提交，给出通过 / 要求修改 / 升级。
5. 归档训练营禁止新邀请与新提交，历史仍可查看。

### 助教（营内 `ta`）

- `/training/manage` 仅列出自己担任助教的营；可看名单、报表、进度、脱敏导出、催交；不能建营/邀请/改角色/存编排。
- `/training/review` 审核本营提交、认领、查看证据卡。
- 导出强制脱敏，无法关闭。

### 学员

1. 用邀请邮箱登录，打开 `/training` 确认已加入训练营。
2. 创建科研项目，选择训练任务（任务可能由馆员编排）。
3. 填写答案与反思，可先存草稿；可用「打开对应智能体」进入 coach 深链。
4. 删除手机号、邮箱、证件号等敏感信息后提交；如提示疑似敏感信息，可**一键遮罩**为 `[EMAIL]` / `[PHONE]` 等占位符。提交会写入**营脱敏同意证明**。
5. 任意任务可添加证据卡并标记核验状态。
6. 若任务包开启 `peerReview`，提交后进入**同伴互评**。
7. 任务页查看反馈时间线；待修改可按反馈再提交。
8. `/training/report` 查看维度分、雷达图、任务明细与反馈，可导出 JSON 或打印 PDF。

## 八、数据与设置

进入 **「设置」** 页：

- **账号**：查看当前用户与角色。
- **存储用量**：查看后端数据统计（目标）。
- **导出备份**：项目数据导出为 JSON。
- **导入备份**：从 JSON 恢复。
- **MCP 工具**：查看集成的学术检索工具状态。

> 💾 数据存储在平台自有的 PostgreSQL，可跨设备访问；仍建议定期导出备份。

## 九、其他功能

- **成本仪表盘**：各智能体 token 消耗与花费统计、趋势。
- **版本历史**：撰写编辑器查看稿件历史并回滚。
- **主题**：单一暗色宇宙主题（深空蓝），无切换开关。
- **运行状态**：运行可取消、可恢复；断线后事件流可续传。

## 十、常见问题

**Q：忘记密码？**
A：联系管理员重置。

**Q：数据存在哪里？会同步吗？**
A：存储在平台自有 PostgreSQL（经后端加密通道访问），可跨设备；外部 AI/检索调用另需同意。

**Q：为什么管理员页面显示 `FORBIDDEN`？**
A：`/training/manage` 仅限 `admin` / `librarian`。请确认 `users.role`。

**Q：为什么显示「尚未加入训练营」？**
A：当前账号没有对应 `enrollments` 记录，或登录邮箱与邀请邮箱不一致。

**Q：AI 调用需要联网吗？**
A：需要。智能体运行由后端调用 DeepSeek；检索调用 Crossref/OpenAlex/Semantic Scholar。

**Q：可以离线使用吗？**
A：目标架构以服务端为准，需要联网。旧本地模式可离线查看已缓存数据。

## 附录：旧使用方式（迁移中）

重构前为**浏览器本地优先**：首次访问设置本地密码（随机盐 + SHA-256，24h 会话）；数据存 IndexedDB（库名 `ischolar-v6-local`）；可选启用 Supabase 协作模式（`NEXT_PUBLIC_COLLABORATIVE_MODE=true`）以启用云端训练营、邮箱邀请与 RLS。忘记本地密码无法找回。这些路径随迁移逐步移除。
